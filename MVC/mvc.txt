MVC : It stands for Model View Controller. It is design pattern used to develop scalable application. It separates application 
into 3 diff responsibilities.
1. Model
2. View
3. Controller


Model => Data layer, model represent, application data, business logic
responsibilities => database interaction, data validation, business rule
e.g. -> public class Customer {
    public string name {get; set;}
}

View => It it UI layer. Responsible for user interface what user sees on browser
e.g. -> form, html, data

Controller => It is brain of MVC. It connect model and view. It handles user request and application flow.
Receives request, call model, send data to view.


Steps for creating MVC :
1. Create on folder -> right click -> open terminal -> code .
2. Run dotnet new mvc -n project_name on the terminal of vsCode
3. Model folder -> Create Student.cs -> add code
4. Controller folder -> Create StudentController.cs -> add code
5. Views folder -> Create Student folder -> Create index.cshtml
6. Run cshtml using dotnet run cmd
